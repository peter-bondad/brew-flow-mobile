# Coffee Brand Identity

Although the application is operational and task-oriented, it should still reflect the BrewFlow coffee brand.

The interface should feel like it belongs to a modern specialty coffee shop.

Users should immediately recognize the warm, welcoming, and premium atmosphere without sacrificing usability.

The design should balance:

- Professional
- Friendly
- Warm
- Minimal
- Modern

Avoid making the application look like a generic enterprise system.

---

# Presentation Matters

A functional interface is not enough.

Every screen should also be visually polished.

Always consider:

- Visual hierarchy
- Alignment
- White space
- Typography
- Color harmony
- Consistent spacing
- Balanced layouts

A beautiful interface builds trust and improves perceived quality.

---

# Coffee Experience

Every screen should subtly communicate the coffee shop's identity.

Use:

- Warm neutral colors
- Rounded corners
- Comfortable spacing
- High-quality product images
- Soft shadows
- Elegant typography

Avoid making the application feel cold or overly corporate.

The experience should resemble walking into a modern café.

---

# Premium Feel

The application should feel premium without becoming flashy.

Prioritize:

- Smooth animations
- Clean layouts
- Soft color palette
- Large product imagery
- Spacious components

Avoid:

- Heavy gradients
- Excessive shadows
- Loud colors
- Cluttered screens

Premium comes from simplicity.

---

# Product Presentation

Products are the primary focus of the application.

Each product should be presented attractively.

Include:

- High-quality image
- Clear product name
- Short description
- Price
- Variant options

The product image should immediately attract attention.

---

# Menu Experience

Browsing the menu should feel enjoyable.

Users should be encouraged to continue exploring products.

Consider:

- Featured drinks
- Seasonal specials
- Recommended products
- Popular items

Avoid long, overwhelming lists.

---

# Visual Hierarchy

Important information should naturally draw attention.

Priority order:

1. Product Image
2. Product Name
3. Price
4. Variant
5. Description

Secondary information should never compete with primary actions.

---

# Delightful Interactions

Small details improve the overall experience.

Examples:

- Smooth button press animations
- Cart badge updates
- Item added confirmation
- Gentle page transitions
- Skeleton loading
- Smooth image loading
- Interactive quantity controls

Micro-interactions should feel natural and never distracting.

---

# Coffee Theme Consistency

Every screen should consistently follow the BrewFlow identity.

Users should never feel that different screens were designed by different people.

Maintain consistency in:

- Colors
- Typography
- Buttons
- Cards
- Icons
- Radius
- Shadows
- Spacing
- Animations

Consistency creates a premium experience.

---

# Emotional Design

The application should feel:

- Inviting
- Relaxing
- Friendly
- Premium
- Trustworthy

Ordering coffee should feel enjoyable rather than transactional.

The interface should encourage users to return.

---

# Final Design Standard

Before considering any screen complete, verify:

- The UI is functional.
- The layout is clean.
- The interface is visually balanced.
- The coffee theme is recognizable.
- Components feel premium.
- Animations are smooth.
- Images are presented beautifully.
- Typography is readable.
- White space is used effectively.
- The overall experience feels polished.

Do not stop at "working."

Aim for an interface that users enjoy looking at and interacting with while remaining fast, intuitive, and efficient.

BrewFlow is not only a business application—it is also an extension of the coffee shop's brand. Every screen should be operationally efficient while visually reinforcing the warmth, quality, and premium experience customers expect from a modern café.
